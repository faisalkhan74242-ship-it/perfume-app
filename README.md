# Faisal Perfumes

A responsive perfume storefront inspired by the Faisal Perfumes brand: refined editorial styling, fragrance discovery, product filtering and search, and a persistent shopping bag.

## Run locally

Open `index.html` in a browser. This is a static front-end prototype and needs no build step.

## Features

- Responsive desktop and mobile layouts
- Product catalog with scent-family filters, search, and price sorting
- Add-to-bag controls, quantity editing, remove actions, and localStorage persistence
- Newsletter signup confirmation
- Checkout placeholder ready to connect to a payment provider

Product names and prices are sample content. Product photography is loaded from Unsplash.
